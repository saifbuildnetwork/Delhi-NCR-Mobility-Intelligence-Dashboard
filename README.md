# Delhi NCR Mobility Intelligence Dashboard

## Project Overview
This Power BI dashboard analyzes rider conversion, demand patterns, pricing behavior, operational performance, customer drop-offs, and revenue recovery using a simulated Delhi NCR mobility dataset.

## Objectives
- Analyze rider conversion funnel
- Monitor demand and pricing trends
- Track operational performance
- Identify customer drop-off reasons
- Measure revenue leakage and recovery

## Dashboard Pages
1. Executive Overview
2. Marketplace Intelligence
3. Pricing & Demand Analytics
4. Operational Performance
5. Customer Friction Lab
6. Financial Intelligence

## Tools Used
- Power BI
- Power Query
- DAX
- Microsoft Excel

## Dataset
Synthetic Delhi NCR mobility dataset containing rider sessions, bookings, payments, fares, ETA, and conversion funnel data.

## Key KPIs
- Total App Opens
- Successful Trips
- Conversion Rate
- Average Waiting Time
- Average Fare
- Revenue Collected
- Revenue Lost
